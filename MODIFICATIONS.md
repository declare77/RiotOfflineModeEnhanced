# RiotOfflineModeEnhanced: modifications to Deceive

RiotOfflineModeEnhanced is a modified version of [Deceive](https://github.com/molenzwiebel/Deceive) by molenzwiebel,
licensed under the GNU General Public License v3.0 (see `LICENSE`). Modified in October 2026.

Changes from upstream Deceive:

- Rebranded to "RiotOfflineModeEnhanced" (set by the `AppName` property in `Deceive.csproj`): app name, executable name, tray menu, chat messages and the fake friend.
- Fake friend shows the default VALORANT player card, and no Premier/clan tag.
- New original app icon (crescent moon with an "offline" ring), generated by `docs/make_icon.py`.
- New README.
- `RiotOfflineModeEnhanced-settings.json` (next to the exe): fake friend name/group/card/title/level, the
  `visibleTo` list and window options. Changes apply live when the file is saved.
- "Visible to" list: while appearing Offline or Mobile, friends on the list are sent your real
  presence directly (`AppSettings.cs`, `FriendDirectory.cs`, `ProxiedConnection.cs`).
- App window (`MainWindow.cs`): status, masking toggle, searchable friends list with
  online state and tick boxes for who can still see you. Opened from the tray icon.
- Window tabs (`MainWindow.cs`): Status, Store and Agent select. The window is larger to fit them.
- Store tab (`StorePanel.cs`): daily store, Night Market and wallet, read from Riot's store service with
  the Riot Client's local session (`ValorantApi.cs`). Names, rarity and pictures come from valorant-api.com
  (`ValorantContent.cs`), cached in `%APPDATA%\Deceive\valorant-content`.
- Agent select tab (`AgentSelectPanel.cs`): your team's names, agents, level, rank, act record and peak rank
  during agent select. Players with a hidden name stay hidden unless they're on your friends list. Requests
  are only made while the tab is open and the window isn't minimized.
- Thread-safe writes to the proxied chat streams.
- The upstream update check is disabled, and error messages no longer send users to Deceive's issue tracker.

Building on Windows: open `Deceive.sln` in Visual Studio 2022 and build Release, or run
`dotnet build Deceive/Deceive.csproj -c Release`. Releases are built by GitHub Actions from this source
(see `.github/workflows/build.yml`).
